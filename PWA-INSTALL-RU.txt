ШАХМАТЫ — GRANDMASTER EDITION
Устанавливаемая версия для Android и iPhone (PWA)

ЧТО ЭТО
Это полноценная автономная веб-игра с поддержкой установки как приложения.
Папку нужно разместить на любом хостинге с HTTPS. После этого игрок открывает
ссылку и устанавливает игру на телефон. Интернет нужен для первой загрузки,
онлайн-комнат и движка; основная оболочка игры сохраняется для офлайн-запуска.

БЫСТРЫЙ ВАРИАНТ ПУБЛИКАЦИИ
1. Создайте статический сайт на Cloudflare Pages, Netlify, GitHub Pages или
   любом другом HTTPS-хостинге.
2. Загрузите в корень сайта ВСЁ содержимое этой папки, включая папки icons и vendor.
3. Откройте адрес сайта один раз в Chrome на Android или Safari на iPhone.

ANDROID
Chrome покажет кнопку «Установить приложение» или:
меню ⋮ → «Установить приложение» / «Добавить на главный экран».

IPHONE / IPAD
Откройте сайт именно в Safari → «Поделиться» → «На экран Домой» → «Добавить».
Игра появится отдельной иконкой и будет запускаться как приложение.

ВАЖНО
— Не открывайте index.html двойным нажатием из файлов: режим установки и
  офлайн-кеш браузер включит только на сайте через HTTPS.
— Не меняйте расположение файлов: service worker, движок Stockfish и иконки
  должны остаться в этой структуре.
— Для магазина Google Play / App Store требуется отдельная нативная сборка,
  учётные записи разработчика и публикация. Этот PWA-пакет уже подходит для
  прямой установки через браузер без магазина.

ФАЙЛЫ
index.html              — игра
manifest.webmanifest    — параметры устанавливаемого приложения
sw.js                   — офлайн-кеш
icons/                  — иконки для Android и iPhone
vendor/                 — локальный движок и сетевая библиотека
